# Limitations and Future Improvements

## Current Limitations

- The database uses fictional sample data rather than real retail data.
- It is designed for a small retail store and has a limited number of records.
- Inventory quantity is stored, but stock does not automatically decrease when an order is completed.
- Payment processing is simulated; it is not connected to a real payment gateway.
- The project does not include user login, roles, or access control.
- The project has no graphical dashboard or web application interface.

## Future Improvements

- Add triggers to automatically update stock when products are ordered.
- Add suppliers and purchase-order management.
- Add employee, store-location, and inventory-movement tables.
- Add customer login and role-based database access.
- Create a Power BI or Tableau dashboard for sales reporting.
- Add stored procedures for common operations.
- Add automated backup scheduling and monitoring.
- Scale the database for multiple stores and larger sales volumes.
